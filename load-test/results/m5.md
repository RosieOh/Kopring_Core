# M5 측정 원본 표 (2026-10-26 오후)

모든 즉시 발급 실행에서 **이벤트 목록 조회(`GET /api/coupon-events`)를 초당 50번** 함께 불렀습니다(`BROWSE_RATE=50`). "다른 API" 열이 그 결과입니다.
서버는 18080 포트의 jar(`java -XX:TieredStopAtLevel=1 -Djdk.tracePinnedThreads=short -jar …`)로 띄웠습니다. M4 는 main `fc0b982` 로 만든 jar 입니다.
모든 실행에서 정확히 쿠폰 수만큼 발급됐고(발급 + 소진 + 503 = 사용자 수), 가상 스레드 고정(pinning)은 MBean 등록을 끈 뒤 0건입니다.

**측정 환경이 크게 흔들렸습니다.** 같은 기계에서 다른 작업이 함께 돌아 부하 평균이 5~106 사이를 오갔고, 같은 M4 를 다시 재도 즉시 발급 응답 중앙값이 3.56초와 12.98초로 갈렸습니다. 아래 표는 **같은 회차 안의 상대 비교**로만 읽어 주세요.
